# The Swatch Book

Thirty-seven art styles, each made into a little game for your phone.

**Play: https://lelelilo-studios.github.io/swatch-book-web/**

Every game draws with WebGPU: Chrome or Edge on a computer or an Android phone, or Safari 26 and later on iPhone,
iPad and Mac. Phones first (portrait, touch); a keyboard works on a computer.

The styles are the 37 of [Game Art Style](https://gameartstyle.loopyhop.com/), a visual atlas of how games see the
world; each game's idea grows out of its style. The games are written in Rust on WebGPU with one shared kit, made with
Claude Code: one session designed the games and the kit, and builder agents made one game each. See
[CREDITS.md](CREDITS.md).

This repository holds only the published build. A collection from Neri's Game Post on
[lelelilo.com](https://lelelilo.com/?ref=swatch-book).
